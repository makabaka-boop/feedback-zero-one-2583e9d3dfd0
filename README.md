# phylo_backend — 筛选偏差校正的树形 CTMC 后端

测序平台只保留**真实叶状态不全相同**（事件 V）的位点。本后端在存在缺测
（`?`）的条件下，对二态（A/C）连续时间马尔可夫链系统发育树计算校正后的
`likelihood = P(E∧V)/P(V)` 与条件期望跳变次数 `counts`。

纯 Python 3 标准库实现（无需第三方包；2×2 矩阵指数与跳变计数矩阵均为闭式解，
条件推断为自写的树剪枝/上下递推）。

## 入口

```
python3 phylo_backend.py INPUT.json OUTPUT.json
```

* 成功：结果**替换**写入 `OUTPUT.json`（临时文件 + 原子重命名），退出码 0。
* 拒绝（任何非法输入、重复或未知成员）：**整次拒绝**，向 stdout 打印一个
  错误 JSON，退出码 1，已存在的 `OUTPUT.json` **保持原样**：

  ```json
  {"status": "error", "path": "$.rates[0][1]", "index": 0, "message": "..."}
  ```

  `path` 为 JSON 路径（下标为零基），`index` 为相关数组零基下标（无则
  `null`）；JSON 语法错误报 `"$"`。

## 输入

顶层对象**恰好**包含 `edges`、`pi`、`Q`、`rates`、`sites` 五个成员；
所有数值均为 `"p/q"` 字符串（p 整数、q 正整数）。

* `edges`：`[[父, 子, t], ...]`；标识符为非空 ASCII 字母数字串；必须构成
  单一有根树且至少两叶；`t ≥ 0`。
* `pi`：`[pA, pC]`，概率且和为 1（精确分数校验）。
* `Q`：2×2 矩阵，非对角元 ≥ 0、行和为 0。
* `rates`：非空 `[[r, w], ...]`，`r ≥ 0`、`w > 0`、`Σw = 1`。
* `sites`：映射数组，每项**恰好**包含全部叶，值为 `"A"`、`"C"` 或 `"?"`
  （`?` 兼容两状态）。

## 模型与输出

每位点独立抽一次速率 r（概率 w）、全树共享；根服从 `pi`；给定父状态，各子
分支独立按 `exp(r·t·Q)` 演化。记 V = 真实叶不全相同，E = 兼容观测。

* 合法空 `sites` 优先返回 `[]`；
* `P(V) = 0` 正常返回 `{"status": "unobservable"}`；
* 否则返回**位点原序**数组：
  * 分子 `P(E∧V) = 0` 的位点仅 `{"status": "impossible"}`；
  * 其余为 `{"likelihood": P(E∧V)/P(V), "counts": [...]}`，`counts` 为条件于
    `E∧V` 的**各边**（按输入边序）期望跳变次数，往返均计数。

联合概率先按速率权重混合再条件化：

```
likelihood = [Σ_r w_r P_r(E∧V)] / [Σ_r w_r P_r(V)]
counts_e   = [Σ_r w_r E_r(N_e·1(E∧V))] / [Σ_r w_r P_r(E∧V)]
```

有限数绝对误差 ≤ 1e-8。

## 计算要点

* `P = exp(rtQ)` 与跳变计数矩阵 `J[i][j] = E[N_t·1(X_t=j)|X_0=i]`
  （`= ∫₀ᵗ e^{Qs} R e^{Q(t-s)} ds`）均为闭式；J 满足可逆性恒等式
  `π₀J₀₁ = π₁J₀₁` 并与数值积分对照验证。
* 树剪枝按 全A/全C/混合 三类部分似然递推，混合类只用非负项累加，
  精确保留 `P(V) = 0`。
* 每边期望跳变用根到叶递推（up-down pass）在 观测/全A/全C 三种叶似然下
  求 `E[N_e·1(·)]`，相减得到 `E[N_e·1(E∧V)]`。

## 验收

```
python3 acceptance_test.py
```

13 组独立小树测试：题目简例（`likelihood=1/2`、
`counts=[0, 1.3130352855]=[0, coth(1)]`）、边序/位点序、全缺测、速率混合、
`impossible`/`unobservable`/空 `sites` 优先级、J 矩阵对数值积分、三叶树全
枚举 + Simpson 积分对照、以及全部非法输入拒绝与输出文件保留/替换语义。
